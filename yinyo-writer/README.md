## 核心理念

写作是技能，可以刻意练习。
真正打动人的，不是滴水不漏的完美，而是一个真实的人，在认真聊一件真正打动自己的事。


## v3.8 热点文章开头立场修复

- 禁止把内部选题/审稿话术放进读者可见正文，例如「蹭热点」「热度可以蹭」「避免把热点写歪」「事实口径」。
- 热点文章的事实边界必须转译成第一人称判断过程：`我刷到...`、`我翻了一圈资料后发现...`、`至少在我看到的公开资料里...`。
- 开头摘要区也必须使用第一人称读者视角，不能写成运营备忘或报告摘要。

## v3.7 尾注规范修复

- 修复 Markdown 固定尾注与 HTML 排版尾注不一致的问题。
- 所有公众号推文尾部必须固定使用：`yinyo 隐曜` / `一人AI实验室，真实评测 · 实用技能 · 自由探索。`
- HTML 版只允许轻量化排版，不允许改成「隐曜杂货铺」、不允许把 `一人AI实验室` 拆成 `一人 AI 实验室`、不允许把分隔点 `·` 改成逗号。

## v3.6 DeepSeek 推文最终版沉淀

- 固化《DeepSeek 给 Agent 装了一根手指》发布过程经验：花叔95分线 → 100+主题视觉化 → 最终融合微调。
- 新增“先达到微信原生阅读感，再让主题长出自己的视觉语言”的方法。
- 沉淀最终HTML参数：紧凑开篇结论、16px首段引用、浅灰坐标块、红色下划重点、标题节奏变化、尾部品牌轻标识。
- 明确技术深度解析的主观表达配比：70%客观机制拆解 + 30%个人判断。

## v3.5 排版升级

- 输出 HTML 样式升级为花叔红色组件长文版，只替换排版层，不改变隐曜写作方法论。
- 按 Codex 对标花叔评分修正：红底白字标题块、正文 `line-height:1.85`、段落 `margin:18px 0`、红色表头、红色轻底强调。
- 目标观感：不再是高级极简，而是更接近花叔原文的微信原生发布质感。

## v3.4 排版升级

- 输出 HTML 样式升级为花叔式95分长文版，只替换排版层，不改变隐曜写作方法论。
- 新规范不只讲结构，还固化了舒服感参数：灰度、间距、摘要块底色、标题字号、代码浅底、尾注轻重。
- 目标观感：不是“像公众号”，而是“读起来明显更舒服”，接近花叔长文的阅读感。

## v3.3 排版升级

- 输出 HTML 样式升级为花叔式极简长文版，只替换排版层，不改变隐曜写作方法论。
- 新规范强调：开头摘要、白底黑字、短段落、判断式标题、朴素表格、轻量代码/坐标块、少卡片、少颜色、少 emoji。
- 目标观感：能撑住 9000 字技术长文的公众号阅读体验，不像模板海报。

## v3.2 排版升级

- 输出 HTML 样式切换为卡兹克式极简阅读版，只替换排版层，不改变隐曜写作方法论。
- 白底黑字、短段落、自然留白，80% 以上内容用普通段落承载。
- 卡片只保留引用、关键总结、链接信息三类；禁止花里胡哨的彩色卡片和 emoji 列表。
- 强调以黑色加粗为主，品牌橙/暗红只用于极少数核心概念或风险提示。

## 核心能力

- **五种文章原型**：调查实验型 / 产品体验型 / 现象解读型 / 工具分享型 / 方法论分享型——先判断类型，再选择写法
- **四层质检体系**：L1硬性规则 → L2风格一致性 → L3内容质量 → L4活人感终审，逐层通过才能发布
- **AI边界定义**：明确划定"AI做了会暴露"的部分——第一手观察、核心创意角度、真实情绪表达，必须人来做
- **升番逻辑**：多个案例逐一展示，每一项带吐槽和情绪，最炸的留到最后
- **文化升维**：从具体事件自然连接到更大的文化/哲学/历史参照物
